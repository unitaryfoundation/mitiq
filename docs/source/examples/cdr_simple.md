# Clifford Data Regression (CDR) with Cirq

In this tutorial, we demonstrate [Clifford Data Regression](../guide/cdr.md) (CDR), a learning-based quantum error mitigation technique. CDR trains an error mitigation model using quantum circuits that resemble the circuit of interest but are easier to classically simulate.

+++

## Setup

First, we import the necessary modules. This example only requires `mitiq`, `cirq`, and `numpy`.

```{code-cell}
import numpy as np
import cirq
from mitiq import cdr, Observable, PauliString
from mitiq.interface.mitiq_cirq import compute_density_matrix
```

## Sample Circuit

We create a simple circuit with both Clifford gates (H, CNOT) and non-Clifford gates (RZ, RX). CDR works best with circuits that are not too short, so we repeat the circuit to increase its depth.

```{code-cell}
a, b = cirq.LineQubit.range(2)
circuit = cirq.Circuit(
    cirq.H.on(a),  # Clifford
    cirq.H.on(b),  # Clifford
    cirq.rz(1.75).on(a),
    cirq.rz(2.31).on(b),
    cirq.CNOT.on(a, b),  # Clifford
    cirq.rz(-1.17).on(b),
    cirq.rz(3.23).on(a),
    cirq.rx(np.pi / 2).on(a),  # Clifford
    cirq.rx(np.pi / 2).on(b),  # Clifford
)

# Increase circuit depth for better CDR performance
circuit = 5 * circuit
print(circuit)
```

## Executors

CDR requires two executors:
1. A **noisy executor** that simulates the circuit with noise (like a real quantum device)
2. A **near-Clifford simulator** that efficiently simulates the near-Clifford training circuits

### Noisy Executor

We create a noisy executor using Cirq's density matrix simulator with depolarizing noise.

```{code-cell}
def noisy_executor(circuit: cirq.Circuit, shots: int = 1000) -> float:
    """Execute circuit with depolarizing noise and return expectation value of |00><00|."""
    # Add depolarizing noise to the circuit
    noise_level = 0.01
    noisy_circuit = circuit.with_noise(cirq.depolarize(p=noise_level))
    
    # Simulate with density matrix simulator
    result = cirq.DensityMatrixSimulator().simulate(noisy_circuit)
    density_matrix = result.final_density_matrix
    
    # Compute expectation value of |00><00|
    return density_matrix[0, 0].real
```

### Near-Clifford Simulator

For the near-Clifford simulator, we use Cirq's state vector simulator without noise. This is efficient for simulating the near-Clifford training circuits generated by CDR.

```{code-cell}
def near_clifford_simulator(circuit: cirq.Circuit, shots: int = 1000) -> float:
    """Execute circuit without noise and return expectation value of |00><00|."""
    result = compute_density_matrix(circuit, noise_level=(0.0,))
    return result[0, 0].real
```

### Ideal Simulator

We also create an ideal simulator to compute the exact expectation value for comparison.

```{code-cell}
def ideal_simulator(circuit: cirq.Circuit) -> float:
    """Compute the exact expectation value of |00><00| without any noise."""
    result = compute_density_matrix(circuit, noise_level=(0.0,))
    return result[0, 0].real
```

## Executing CDR

Now we can use CDR to mitigate the errors. We compare the unmitigated and mitigated results against the ideal value.

```{code-cell}
# Compute ideal expectation value
ideal_expval = ideal_simulator(circuit)
print(f"Ideal expectation value: {ideal_expval:.4f}")

# Compute unmitigated expectation value
unmitigated_expval = noisy_executor(circuit)
print(f"Unmitigated expectation value: {unmitigated_expval:.4f}")

# Apply CDR error mitigation
mitigated_expval = cdr.execute_with_cdr(
    circuit,
    noisy_executor,
    simulator=near_clifford_simulator,
    random_state=42,
)
print(f"Mitigated expectation value: {mitigated_expval:.4f}")
```

## Results

Let's quantify the improvement achieved by CDR.

```{code-cell}
unmitigated_error = abs(unmitigated_expval - ideal_expval)
mitigated_error = abs(mitigated_expval - ideal_expval)

print(f"Unmitigated error: {unmitigated_error:.4f}")
print(f"Mitigated error: {mitigated_error:.4f}")

if mitigated_error > 0:
    improvement_factor = unmitigated_error / mitigated_error
    print(f"Improvement factor: {improvement_factor:.2f}x")
else:
    print("CDR achieved perfect mitigation!")
```

## How CDR Works

CDR works by:
1. **Generating near-Clifford circuits**: CDR creates variants of the original circuit where non-Clifford gates are replaced with Clifford gates
2. **Training on near-Clifford circuits**: These near-Clifford circuits are simulated both with and without noise to learn the noise model
3. **Applying the learned model**: The learned noise model is applied to mitigate errors in the original circuit

The key insight is that near-Clifford circuits can be efficiently simulated classically, allowing us to learn the noise characteristics without expensive quantum computations.

## Conclusion

In this tutorial, we demonstrated how to use CDR with a simple Cirq circuit. CDR effectively reduces errors by learning from near-Clifford circuit variants. The mitigated result is closer to the ideal value compared to the unmitigated result.
