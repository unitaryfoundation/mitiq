# Zero-noise extrapolation with a QuTiP-QIP backend

Use a [QuTiP-QIP](https://qutip-qip.readthedocs.io/en/stable/)
gate-level backend to run circuits generated by Mitiq's
[zero-noise extrapolation (ZNE)](../guide/zne.md).
You will build a two-qubit circuit in Cirq, simulate it with QuTiP-QIP and
QuTiP density matrices, and extrapolate its noisy expectation values.
This example uses exact simulation and a deliberately simple noise model;
it does not require hardware access or sampling.

Install `qutip==5.3.0` and `qutip-qip==0.4.2` alongside Mitiq to run this
example. These packages are also included in Mitiq's documentation
dependency group.

## Prepare a circuit

The Hadamard and controlled-X gates prepare a Bell state. The subsequent
Z rotations preserve its ZZ expectation value of 1, which gives you a
reference for checking the noisy and mitigated results.

```{code-cell} ipython3
import cirq
import numpy as np
import qutip as qt
from qutip_qip.circuit import QubitCircuit

from mitiq import zne
from mitiq.zne.inference import RichardsonFactory
from mitiq.zne.scaling import fold_global

q0, q1 = cirq.LineQubit.range(2)
circuit = cirq.Circuit(
    cirq.H(q0),
    cirq.CNOT(q0, q1),
    [cirq.rz(0.2)(q0) for _ in range(8)],
)
print(circuit)
```

## Pass individual gates to QuTiP-QIP

QuTiP-QIP's
[`QubitCircuit`](https://qutip-qip.readthedocs.io/en/stable/apidoc/qutip_qip.circuit.html#qutip_qip.circuit.QubitCircuit)
accepts custom unitary gates. Register each Cirq operation's matrix and
preserve the order of its qubits in `targets`. QuTiP-QIP then expands each
gate onto the full register when you call `propagators()`.

This small adapter handles resolved unitary qubit operations, including
their inverses from folding. Measurements, channels, symbolic parameters,
and classical controls are outside its scope.

```{code-cell} ipython3
def to_qutip(circuit: cirq.Circuit) -> QubitCircuit:
    """Translate resolved unitary qubit operations to custom QIP gates.

    Args:
        circuit: Unitary circuit with resolved parameters and qubits.

    Returns:
        Circuit with custom gates in the sorted qubit order.
    """
    qubits = sorted(circuit.all_qubits())
    converted = QubitCircuit(len(qubits))
    for index, operation in enumerate(circuit.all_operations()):
        dims = [2] * len(operation.qubits)
        name = f"gate_{index}"
        converted.user_gates[name] = qt.Qobj(
            cirq.unitary(operation), dims=[dims, dims]
        )
        converted.add_gate(
            name, targets=[qubits.index(q) for q in operation.qubits]
        )
    return converted


converted = to_qutip(circuit)
assert np.allclose(converted.compute_unitary().full(), cirq.unitary(circuit))
```

## Define the noisy executor

Define a synthetic global depolarizing channel after each gate:
$\rho \mapsto (1-p)\rho + p I/4$.
The same channel acts after both one-qubit and two-qubit gates in this
example. This is an illustrative model, rather than a calibration of a
physical device. For other simulation models, see
[QuTiP-QIP's noise guide](https://qutip-qip.readthedocs.io/en/stable/qip-noise.html).

The executor starts from $|00\rangle$, applies the expanded gate matrices
and noise using QuTiP, and returns the ZZ expectation value. Keep all gates
when executing folded circuits so that the inserted gates also incur noise.

```{code-cell} ipython3
def execute(circuit: cirq.Circuit, noise: float = 0.01) -> float:
    """Return the ZZ expectation for a two-qubit unitary circuit.

    Args:
        circuit: Circuit to simulate, with exactly two qubits.
        noise: Global depolarizing probability after each gate.

    Returns:
        Expectation value after noisy density-matrix evolution.
    """
    if len(circuit.all_qubits()) != 2:
        raise ValueError("This executor expects exactly two qubits.")
    converted = to_qutip(circuit)
    rho = qt.tensor(qt.basis(2, 0), qt.basis(2, 0)).proj()
    mixed = qt.qeye([2, 2]) / 4
    for gate in converted.propagators():
        rho = (1 - noise) * gate * rho * gate.dag() + noise * mixed
    return float(qt.expect(qt.tensor(qt.sigmaz(), qt.sigmaz()), rho))


ideal = execute(circuit, noise=0.0)
raw = execute(circuit)
assert np.isclose(ideal, 1.0)
print(f"Noiseless ZZ: {ideal:.6f}")
print(f"Noisy ZZ:     {raw:.6f}")
```

## Fold, execute, and extrapolate

Use global folding with scale factors 1, 3, and 5. Each inserted
$U^\dagger U$ preserves the noiseless computation. A Richardson factory
extrapolates the three noisy results to zero noise
{cite}`Temme_2017_PRL,Li_2017_PRX`.

```{code-cell} ipython3
scale_factors = [1.0, 3.0, 5.0]
factory = RichardsonFactory(scale_factors)
mitigated = zne.execute_with_zne(
    circuit, execute, factory=factory, scale_noise=fold_global
)

for scale in scale_factors:
    folded = fold_global(circuit, scale)
    assert np.isclose(execute(folded, noise=0.0), ideal)

print(f"Mitigated ZZ: {mitigated:.6f}")
print(f"Raw error:    {abs(raw - ideal):.6f}")
print(f"ZNE error:    {abs(mitigated - ideal):.6f}")
assert abs(mitigated - ideal) < abs(raw - ideal)
```

```{code-cell} ipython3
import matplotlib.pyplot as plt

factory.plot_fit()
plt.axhline(ideal, color="black", linestyle=":", label="Noiseless ZZ")
plt.ylabel("ZZ expectation value")
plt.legend()
plt.show()
```

The assertions check the noiseless reference and the improvement for this
specific circuit and noise strength. Other noise models and circuits may
need different scaling or inference choices; ZNE does not guarantee an
improvement for every backend. To use your own backend, replace the
executor's simulation while retaining its circuit-to-expectation-value
interface. See the [executor guide](../guide/executors.md) for the contract.
